# Arch Linux

Daftar paket dan catatan administrasi sistem. `install.sh` memakai `packages/dwm.txt` dan `packages/development.txt` untuk memasang lingkungan X11/dwm. Kernel, bootloader, jaringan, dan partisi diasumsikan sudah dikonfigurasi pada Arch minimal. File di direktori `etc/` adalah dokumentasi/template, bukan instruksi untuk menimpa seluruh `/etc`.
